## 프로젝트 목표:
1. CloudFormation 템플릿을 사용한 AWS 기본 인프라 구축
2. OpenVPN Access Server를 활용한 안전한 원격 접속 환경 구축
3. ALB와 Global Accelerator를 통한 글로벌 고가용성 확보
4. Auto Scaling Group을 통한 탄력적 운영 구현
5. ACM과 WAF를 활용한 웹서비스 보안 강화
6. VPC Peering을 이용한 멀티리전 사설망 구현
7. 고객 정보와 고객에게 제공되는 정보는 RDS에 보관하는 것을 원칙으로 함
8. S3와 CloudFront를 이용한 안전한 CDN 스트리밍 구현
9. EC2 + Apache + PHP 프론트엔드 구현
10. RDS를 활용한 회원가입 및 로그인 플랫폼 구축
11. 신뢰성 있는 정보를 바탕으로 한 고가용성 정보 제공
12. AI를 활용한 벡터 검색, 사전 태깅 아키텍쳐 구현을 통한 맞춤형 서비스 제공

### b. 추가 목표(향후 프로젝트)

1. 해외 타 리전과도 연결 활성화
2. AWS CloudWatch를 이용한 리소스 모니터링, 로그, 알람, 자동화 구현
3. EC2 인스턴스의 컨테이너화
4. 해당 상권에 살리기를 위한 구차원에서 협업
5. 해외 접속 시 해당 리전에 맞는 표준 시간대로 변경하여 조회
